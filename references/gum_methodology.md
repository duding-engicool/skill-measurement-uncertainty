# GUM 测量不确定度评定方法（公开概述参考）

> ⚠️ 免责声明：本文件为 GUM（ISO/IEC Guide 98-3 / JCGM 100:2008《测量不确定度表示指南》）**公开方法论的概述性整理**，并非标准原文转载。正式评定须以官方发布版本及企业计量规范为准；文中公式、分布换算、k 值等若与企业认可准则冲突，以企业规范与授权计量人员判定为准。缺失参数请标注「待企业补充」。

## 1. 基本概念

- **测量不确定度**：表征合理赋予被测量之值的分散性，与测量结果相联系的参数。
- **标准不确定度 u(x)**：以**标准偏差**表示的不确定度。
- **A 类评定**：用**统计方法**对重复观测列评定（实验数据）。
- **B 类评定**：用**非统计方法**（校准证书、设备说明书、经验、先验信息）评定。
- **合成标准不确定度 u_c(y)**：各分量合成后的标准不确定度。
- **扩展不确定度 U = k·u_c(y)**：给出更高置信水平区间，k 为包含因子。
- **包含概率 p**：通常取 95%（约）；k=2 时约为 95%，k=3 约为 99.7%。

## 2. A 类评定（统计法）

对重复观测列 q₁…qₙ：

- 算术平均值：q̄ = Σqᵢ / n
- 实验标准差：s(q) = √[ Σ(qᵢ − q̄)² / (n − 1) ]
- **平均值的标准不确定度**：u_A = s(q̄) = s(q) / √n

> 注：n 为重复测量次数。建议 n ≥ 6（具体最低要求以企业计量规范为准，待企业补充）。n 越小，自由度越低、u_A 越不稳健。

## 3. B 类评定（非统计法）

已知包含区间半宽 a 与分布假设，标准不确定度：

- **矩形（均匀）分布**：u = a / √3
- **三角分布**：u = a / √6
- **梯形分布**（对称，顶宽比 β，β=0 为三角、β=1 为矩形）：u = a · √[ (1+β²) / 6 ]
- **正态分布**（含 k_B）：u = a / k_B（k_B=2 → 约 95.45%；k_B=2.58 → 99%；k_B=3 → 99.73%）
- **反正弦（正弦）分布**：u = a / √2
- 若证书直接给出**扩展不确定度 U 与包含因子 k**：则 u = U / k

> B 类来源常见：仪器分辨率、校准证书不确定度、温度/湿度影响、读数误差、参考量值、数字量化等。

## 4. 灵敏度系数与合成

数学模型 Y = f(x₁, …, xₙ)。线性近似下，各输入量对输出的不确定度贡献：

- 灵敏度系数 cᵢ = |∂Y/∂xᵢ|
- 输出分量 uᵢ(y) = cᵢ · u(xᵢ)

**合成标准不确定度**（输入量独立时）：

- u_c(y) = √[ Σ (cᵢ · u(xᵢ))² ] = √[ u_A² + Σu_B² ]

> 若输入量间存在相关性，需加入协方差项（实际多数情形可假定独立，存疑标注「待企业补充」）。

## 5. 有效自由度与包含因子（进阶）

- **有效自由度**（Welch–Satterthwaite 近似）：
  ν_eff = u_c⁴(y) / Σ [ uᵢ⁴(y) / νᵢ ]
  其中 νᵢ 为各分量自由度（A 类 ν = n−1；B 类按信息可靠度估算，常见 ν=∞ 或较低值）。
- **包含因子 k**：按置信概率 p 查 t 分布，k = t_p(ν_eff)。
  - 通常近似取 **k = 2**（ν_eff 较大时约 95%）。
  - 自由度很小时应查表取对应的 k（如 ν=5、p=95% → k≈2.57）。

## 6. 结果表达

- 扩展不确定度：U = k · u_c(y)
- 测量结果表达：Y = ȳ ± U (k = …，p ≈ 95%)
- 用于合格判定时，将 U 与规范限/公差比较，并说明风险方向。

## 7. 与 MSA 的区别（易混点）

| 维度 | 测量不确定度 MU（本技能） | 测量系统分析 MSA |
|------|--------------------------|------------------|
| 目的 | 量化**单次测量结果**的不确定程度（计量学） | 评价**测量系统本身**的变异（质量控制） |
| 核心指标 | u_c、U、k | Gage R&R%、偏倚、线性、稳定性 |
| 适用 | 校准/检测报告、合格判定 | 过程能力、量具选型、系统稳定性监控 |
| 关系 | 两者不可互相替代；MU 偏"测得准不准"，MSA 偏"系统稳不稳" | 见上 |

> 本技能只做 MU 评定，不做 MSA 的 Gage R&R 计算（由 `msa-analysis` / `msa-calculator` 承担）。
